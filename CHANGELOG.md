# Changelog

All notable changes to Dream Invoice will be documented in this file.

This project follows a simple pre-1.0 release process while the public foundation, demo app, landing page, server worker, and future desktop editions are being stabilized.

## Unreleased

## 0.1.0 - Public Foundation

- Prepared the Dream Invoice monorepo with web, demo, landing page, desktop, pro-desktop, server API, worker, admin, accounting, shared packages, Docker, and release safety foundations.
- Added public demo and landing safety checks to prevent real customer data or legacy reference names from being published.
- Added development Docker helpers for PostgreSQL, Mailpit, and Adminer.
- Added flow smoke test foundations for future web, server, desktop, and pro scenarios.
