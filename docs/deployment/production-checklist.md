# Production Checklist

Use this checklist before handing over a Dream Invoice installation.

## 1. Environment

- [ ] `.env` was generated by `scripts/install.sh` or created from `.env.example`
- [ ] No `CHANGE_ME_*` placeholder remains in `.env`
- [ ] `.env` is not committed and is readable only by trusted operators
- [ ] `AUTH_SECRET` was generated with a strong random value
- [ ] `AUTH_COOKIE_SECURE` matches the public URL scheme
- [ ] `POSTGRES_PASSWORD` was generated with a strong random value
- [ ] `DREAM_INVOICE_AUTH_REQUIRED=true` before public exposure
- [ ] `DREAM_INVOICE_AUTH_PASSWORD` was generated with a strong random value
- [ ] `DREAM_INVOICE_ADMIN_PASSWORD` was generated with a strong random value
- [ ] Login rate limits match the deployment risk profile
- [ ] `LICENSE_PUBLIC_KEY` is configured when licensing is used
- [ ] SMTP settings are configured when email sending is enabled

## 2. Docker Stack

- [ ] `ghcr.io/dream-de/invoice-app:latest` is reachable from the server
- [ ] `docker compose pull` succeeds
- [ ] `docker compose up -d` starts successfully
- [ ] `docker compose ps` shows healthy services
- [ ] PostgreSQL volume is persistent
- [ ] Optional Nginx proxy profile is enabled only when needed
- [ ] Maintainer-only local builds use `docker-compose.build.yml`

## 3. Network And TLS

- [ ] HTTPS is configured at the reverse proxy or hosting layer before public exposure
- [ ] App URL points to the intended domain or host
- [ ] PostgreSQL is reachable only from the intended network
- [ ] Firewall rules match the deployment plan
- [ ] Server time is synchronized with NTP

## 4. App Setup

- [ ] First owner account was created
- [ ] Setup route is closed after owner creation
- [ ] Login works
- [ ] Logout works
- [ ] Protected app routes require a valid session
- [ ] Mutating API routes use the request guard
- [ ] User roles and permissions were reviewed

## 5. Data And Backups

- [ ] Database schema updates are applied
- [ ] Backup schedule exists
- [ ] Restore procedure was tested
- [ ] Backups are stored outside the application directory
- [ ] Upload and export directories are included where relevant
- [ ] Log retention is defined

## 6. License

- [ ] License activation succeeds with a valid license key
- [ ] Invalid license keys are rejected
- [ ] User limits are displayed correctly
- [ ] User creation respects the active license limit

## 7. Final Smoke Test

- [ ] `./scripts/status.sh` returns expected statuses
- [ ] Dashboard opens
- [ ] Customer list opens
- [ ] Customer creation opens
- [ ] Article list opens
- [ ] Document list opens
- [ ] Invoice PDF route works
- [ ] Placeholder PDF routes return controlled unavailable responses
- [ ] Settings pages open
- [ ] Finance overview opens
- [ ] Import template endpoints respond
- [ ] Export endpoints respond
