# Code of Conduct

Dream Invoice should be a professional and respectful project space.

## Expected Behavior

- Be respectful and constructive
- Keep feedback focused on the work
- Assume good intent, but accept correction
- Use clear reproduction steps for bugs
- Protect private data, credentials, and customer information
- Be patient with early-stage foundation work

## Unacceptable Behavior

- Harassment, insults, threats, or discriminatory language
- Publishing private information or credentials
- Sharing real customer, bank, invoice, or license data in public discussions
- Deliberately disrupting issues, reviews, or maintainers
- Pressuring maintainers for unpaid urgent work

## Financial Software Responsibility

Dream Invoice handles workflows related to invoices, customers, documents, finance, and licensing. Discussions and contributions must avoid exposing real business data.

Use fictional data in:

- Issues
- Pull requests
- Screenshots
- Demo data
- Tests
- Documentation examples

## Reporting

For behavior concerns, contact the repository owner privately when possible.

For security-sensitive reports, follow [SECURITY.md](./SECURITY.md).

## Enforcement

Maintainers may edit, hide, or remove comments, issues, pull requests, or contributions that violate this code of conduct. Repeated or severe violations may result in restricted participation.
