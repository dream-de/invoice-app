# Roadmap

This roadmap describes the current product direction for Dream Invoice.

## Product Stability

- Keep installation simple for self-hosted deployments
- Keep demo and landing-page services separate from the product stack
- Keep Docker, environment, and migration flows easy to verify
- Improve documentation where setup or operation is unclear

## App Workflows

- Strengthen dashboard, customer, article, document, project, finance, and settings workflows
- Improve import and export coverage
- Expand PDF template quality and rendering consistency
- Keep login, session, setup, and user management flows reliable

## Licensing

- Maintain signed license verification
- Maintain user-limit enforcement in app and database layers
- Improve license status visibility in settings
- Keep license tooling documented for maintainers

## Operations

- Improve backup and restore guidance
- Improve deployment smoke tests
- Keep Docker health checks and status scripts useful
- Improve release notes and update guidance

## Desktop And Companion Apps

- Keep desktop, Pro, accounting, admin, worker, and server-api workspaces aligned with the main product architecture
- Promote shared packages when workflows are ready to reuse logic across apps
- Avoid duplicating business rules between apps

## Principles

- Product stack first
- Clear install path
- Fictional demo data
- Signed licensing
- Server-side authorization
- Database-backed integrity
- Documentation that matches the current code
