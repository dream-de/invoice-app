## Questions And Setup Help

For non-sensitive questions, use GitHub issues when issues are enabled.

Good support requests include:

- What you tried
- Expected behavior
- Actual behavior
- Relevant command output
- Operating system, Node.js version, pnpm version, and Docker version
- Screenshots for UI problems, using fictional data only

## Security Issues

Do not open public issues for security-sensitive reports.

Use the guidance in [SECURITY.md](./SECURITY.md) for:

- Secrets exposure
- Authentication or authorization issues
- License key handling issues
- Database or deployment security concerns
- Real customer data exposure
